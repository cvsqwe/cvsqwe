## Проекты

### 🏝️ [cove](https://github.com/cvsqwe/cove)
Своя экосистема на Hyprland: шелл на Quickshell, IDE Cove Code, Firefox и терминал в одном стиле.
Цвета берутся из обоев и применяются ко всему сразу, без перезапуска. Внутри: верхняя панель в 8 стилях, динамический остров, лаунчер, центр управления, 19 виджетов, скриншоты с редактором, запись экрана, распознавание текста и QR, менеджер задач, экранное время. Интерфейс на русском и английском.
<sub>QML · Quickshell · Textual · Arch Linux</sub>

### ⌨️ [OpenAula](https://github.com/cvsqwe/OpenAula)
Открытый драйвер подсветки и макросов для клавиатуры Aula F75 под Linux. Около 40 эффектов, рисование по клавишам, слои, переназначение клавиш и макросы. Настройка через веб-интерфейс в браузере.
<sub>C++17 · hidapi · evdev</sub>

### 🤖 [matele](https://github.com/cvsqwe/matele)
Один бот — два мессенджера: асинхронный Python-фреймворк для ботов в MAX и Telegram. Типизированный клиент ко всему MAX Bot API (модели генерируются из официальной схемы), роутеры, FSM, фильтры, middleware.
<sub>Python · asyncio · httpx</sub>

### 🎨 [MD4H](https://github.com/cvsqwe/MD4H-My-Dotfiles-For-Hyprland-)
Мои дотфайлы для Hyprland.
<sub>Shell</sub>
